# 班车助手（NudtBus13）

<p align="center"><img src="assets/og-image.jpg" alt="班车助手" width="560"></p>

> 校区通勤 × 院内通勤，双向班车规划。基于公开班车时刻信息与真实地图校验的复刻升级版。

**🌐 在线使用：https://jensen-yao.github.io/NudtBus13/**

## ✨ 功能

- **🚌 校区通勤模式（全网全集）**：全部 17 个站点任意组合——一号院 ↔ 三号院 ↔ 科大佳园/景园/四号院，8号线 + 线路1~7 + 学院专线，跨线路智能规划
- **🏫 院内通勤模式（生活圈视图）**：三号院生活圈（环线1路、环线3路观光车、就餐专线）、一号院生活圈、四号院……按院区生活圈分组，数据驱动自动扩展
- **📋 规划式交互**：点击「从哪出发」「去哪上班」弹出站点选择器（搜索 + 常用站点记忆），⇅ 一键反向
- **⏱️ 实时倒计时**：下一班每秒刷新，即将发车脉冲提醒
- **👥 拥挤提示**：早高峰/午间热门班次自动标注拥挤等级
- **🙋 我准备坐这班**：一键标记当天计划乘坐的班次（本地记忆）
- **📖 班车表明细**：完整时刻表一键展开，周一至四/周五/周六/周日四套运行表切换，点线路卡片地图高亮
- **🗺️ 线路地图**：站点坐标经 OSM 校准（GCJ-02 纠偏），精度分级标注
- **📅 节假日感知**：2026 全年节假日 + 假期停运横幅自动切换

## 🚀 使用

纯静态站点，无需安装：

```bash
python -m http.server 8000   # 本地预览 http://localhost:8000
```

支持 PWA「添加到主屏幕」。
